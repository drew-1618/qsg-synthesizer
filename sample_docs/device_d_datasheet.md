# Halden FX-600 — Datasheet

## Overview

The Halden FX-600 is a residential Wi-Fi 6 gateway with an integrated
GPON ONT for fiber-to-the-home deployments.

## Key Features

- Integrated GPON ONT
- 2x FXS ports for VoIP
- Mesh Wi-Fi support

## Specifications

| Specification | Value |
|---|---|
| Wi-Fi Standard | 802.11ax (Wi-Fi 6), dual-band |
| WAN Speed | Up to 2.5 Gbps (GPON) |
| Form Factor | Desktop |
| Max Wireless Throughput | 3 Gbps combined |
| Power Consumption | 15 W typical |
| Operating Temperature | 0 to 40 °C |
| Battery Backup | Optional 12 V input |
